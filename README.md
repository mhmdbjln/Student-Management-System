# Student and Teacher Management System

A command-line student and teacher record-management project written in Python using object-oriented programming and text-file storage.

## Features

- Defines `Person`, `Student`, `Teacher`, and `StudyGroup` classes.
- Adds, updates, searches, and lists student records.
- Adds, updates, searches, and lists teacher records.
- Associates students with study groups and assigns advisor teachers.
- Identifies and displays the top three students in a selected study group based on recorded averages.
- Stores records in local text files.

## Run

```bash
python class_for_project.py
```

Follow the numbered menu in the terminal.

## Data files

The application uses local text files such as `filestudent.txt`, `fileteacher.txt`, `fileadvisor.txt`, `filegroup.txt`, and `filebeststudent.txt`. These are created or updated by program write operations. Keep any files containing real student information private and do not commit them to a public repository.

## Requirements

Python 3 only. The project uses the standard library and has no third-party package requirements.
